# MoonCast 项目申报书

## 1. 项目名称

MoonCast：基于 MoonBit 的纯 P2P 直播协作系统

## 2. 项目简介

MoonCast 是一个运行在浏览器中的多人直播协作应用。房主共享屏幕画面和来源声音，成员之间进行实时语音；音视频通过 WebRTC 在浏览器间直接传输，信令服务器只转发 SDP、ICE 和房间事件，不接收、存储或转发媒体数据。

客户端主逻辑由 MoonBit 实现，负责房间状态、成员状态、语音与画面双通道连接、offer/answer 协商、trickle ICE、控制消息、连接恢复和浅层树拓扑规划。浏览器桥接层仅封装 DOM、媒体采集和 WebRTC 原生 API。

## 3. 项目方向与通用性

项目方向为 MoonBit 实时协作应用与 WebRTC P2P 媒体基础设施。

通用性说明：MoonCast 的核心能力可复用于远程办公、在线教学、设计评审、多人演示和轻量直播等场景。其 MoonBit 状态机、双通道连接模型、拓扑规划器和浏览器 API 桥接层均可抽出为通用实时协作基础模块，也可迁移到其他需要低延迟媒体共享的 Web 应用中。

## 4. 预期使用场景

1. **远程结对编程与运维协作**：房主共享 IDE 或终端，成员通过语音 mesh 讨论；观众可按网络情况选择 720p30、1080p30 或 1080p60 画质。
2. **线上课程与实验演示**：教师共享课件、代码或实验软件，并共享系统声音；学生加入同一房间后自动接收画面和语音，无需安装客户端。
3. **设计评审与多人观看演示**：房主共享设计稿或产品演示，多位观众通过浅层树拓扑接收画面；中转节点离开后系统自动重规划剩余链路。

## 5. 拟实现的核心功能

- 房间创建、6 位房间码加入、成员状态展示与房主关闭房间。
- 每对成员一条独立语音 PeerConnection，形成全连接语音 mesh。
- 房主屏幕视频与来源音频共享，支持共享声音开关和麦克风静音。
- 浅层树画面转发：观众不超过 3 人时房主直连；更多观众时最多 3 个第一层中转，树深不超过两层。
- 成员加入或离开后自动重规划拓扑并恢复剩余画面链路。
- 三档画质：流畅 720p30 / 5 Mbps，清晰 1080p30 / 10 Mbps，高帧 1080p60 / 20 Mbps。
- ICE 自动恢复：`failed` 立即重启，`disconnected` 延迟观察，最多 3 次自动恢复，并支持手动重连。
- STUN 打洞并拒绝 TURN/relay 候选，保持媒体链路纯 P2P。
- MoonBit 拓扑单元测试、信令服务器测试、构建脚本和可复现浏览器演示流程。

## 6. 项目来源说明

本项目为原创项目。架构设计参考本人已有公开项目 Syncast 的实践经验，但 MoonCast 的 MoonBit 客户端状态机、拓扑规划器、浏览器桥接层和信令服务器均为重新实现，未复制 Syncast 代码。
